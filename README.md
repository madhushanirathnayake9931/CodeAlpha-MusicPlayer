# 🎵 CodeAlpha - Music Player

A responsive and interactive Web Music Player application built using HTML, CSS, and JavaScript.

---

## ✨ Features
- 🎶 **Play / Pause / Next / Previous** controls
- 📜 **Interactive Playlist:** Select songs directly from the track list
- 🔊 **Volume Control:** Adjust audio volume seamlessly
- ⏳ **Progress Bar:** Real-time track duration and seek functionality
- 📱 **Responsive UI:** Clean and modern glassmorphism design

---

## 🛠️ Tech Stack
- **HTML5** - Structure and audio elements
- **CSS3** - Styling, responsive layouts, and animations
- **JavaScript (ES6)** - Audio API handling and playlist state management
- **Font Awesome** - Control icons
